# Selected-work wave-planning corpora (RIPR-SPEC-0271, #1706)

Corpus for the execution-wave planning consumer in
`xtask/src/work_wave_identity.rs` (#1706, delivery slice PR B, consuming
#1634). The check validates committed `WorkWavePlanV1` rows against a
`PortfolioBasisV1` compiled from immutable captured inputs; it selects no
work, admits no wave, and mutates nothing. `check-fixture-contracts`
recomputes the provenance digests fail-closed.

## Layout

- `corpus.json` — the six required scenarios. Each scenario names the
  captured portfolio directory it binds against (referenced, never
  duplicated) and one or more plan cases. A case carries a
  `WorkWavePlanV1` row, the expected outcome (`pass`/`fail`) and the exact
  expected law/route pairs for failures. Every plan embeds the full
  selected candidate set as `SelectedWorkIdentityV1` packets, so the
  RIPR-SPEC-0244 selection laws run inside the wave check before the
  wave-level laws.
- `author_corpus.py` — regenerates `corpus.json` against the committed
  RIPR-SPEC-0244 selection corpus; edit both together.
- `provenance.json` — per-file SHA-256 bindings in the RIPR-SPEC-0223
  provenance convention under the `work_wave_identity_provenance.v1`
  schema version.

## The six scenarios

1. `wave-01-disjoint-cross-campaign-waves-pass` — the editor-ux and
   rust-repair selections run as independent waves over disjoint exclusive
   resources while sharing the read-only `portfolio-schema` and
   `spec-ledger` references.
2. `wave-02-single-agent-wave-passes-despite-active-campaigns` — the
   narrow single-agent issue `9202` gets its own wave while another
   campaign's wave stays active.
3. `wave-03-overlapping-exclusive-resources-fail` — the exclusive
   `output-contract:preview-panel` shared by two waves forces reconcile.
4. `wave-04-retired-active-goal-resource-fails-closed` — the retired
   generic `active-goal` resource and a non-explicit shape each fail with
   the explicit-vocabulary route.
5. `wave-05-stale-basis-and-unassigned-candidate-fail` — a stale basis
   routes recompilation; a selected candidate assigned to no wave fails
   visibly.
6. `wave-06-capacity-exceeded-fails` — a wave above the declared writer
   capacity forces reconcile.

## Regeneration

```bash
python3 fixtures/work_wave_identity/author_corpus.py
```

Commit the regenerated bytes together with any SPEC.md/scenario-pin change,
then refresh the `provenance.json` digests.
