Find the assertion
your change needs.

Tests below and above the discount threshold can pass with either > or >=. An equality case, with an assertion on the result, distinguishes the behaviors.

ripr calls that distinguishing input or assertion a discriminator. Its finding gives you evidence to inspect and a concrete next step.

Know what the evidence means

A guide to the next test.

ripr analyzes source statically. It does not run your tests or mutants, and it does not prove a test would fail. A quiet or limited result is not a clean bill of health. Run your project’s tests and use runtime mutation testing when you need that evidence.

01 / Install

Get the published CLI

This pinned install uses 0.10.0. Cargo compiles from source and needs Rust 1.95+. The diff workflow needs Git.

cargo install ripr --version 0.10.0 --locked
ripr --version

Prefer a prebuilt binary? The 0.10.0 release assets include platform archives and SHA-256 files. For the installed CLI, follow the 0.10.0 usage guide.

02 / Inspect

Check a committed change

In your Rust repository, use a branch with committed changes and an existing local main branch:

ripr check --base main

Choose another existing ref if needed. Read the changed behavior, related tests, and suggested next test. Use ripr doctor if setup fails.

No findings can also mean an empty diff or limited static evidence.
