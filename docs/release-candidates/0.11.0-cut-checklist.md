# RIPR 0.11.0 cut checklist

Status: **draft, 2026-09-22.** This is the working checklist from "blocker PRs
green" to "0.11.0 published and back-synced". It sequences the existing
contracts in [`RELEASE_TRANSACTION.md`](../RELEASE_TRANSACTION.md),
[`swarm-development.md`](../swarm-development.md#promotion-back-to-source) and
[`RELEASE.md`](../RELEASE.md). Those documents stay authoritative for the exact
commands and receipts. Nothing in this file authorizes a tag, release,
registry upload, marketplace publish, secret, or settings change. Source issue
[ripr#1470](https://github.com/EffortlessMetrics/ripr/issues/1470) remains the
publication boundary.

Each step names who does it. **Claude** means an agent session acting under
Steven's 2026-09-22 direction: it prepares everything, and it runs the
history-preserving sync itself. **Steven** means an owner action nobody else
takes.

## 8. Recording the external-review gap

CodeRabbit posts a `success` status on Claude-authored PRs while skipping them
("Review skipped: bot user not eligible for review"). Repository rules
already treat skipped or unavailable review as missing review. See
`.claude/skills/review-pr/SKILL.md` and `docs/LEARNINGS.md`, "CodeRabbit
Silence Is Not Approval".

How the release records it:

1. Before merging a Claude-authored PR, comment `@coderabbitai review` on it.
   CodeRabbit's skip message offers this single on-demand review for bot
   authors. Where that review then runs, it counts as external review at the
   head it names.
2. The promotion PR body lists every PR in the promoted range where CodeRabbit
   still skipped the PR or reviewed an older head, with
   `external_review: missing`. The green status is never counted as a
   review.
3. For each of those PRs, the list names the review evidence that does exist
   at that PR's merged head: the exact-head `review-pr` COMMENT review, the
   `ub-review` decision, `droid-review` if it ran, and the required checks.
   If none exists, it says so.
4. Before the pin, one review pass covers the combined diff of the
   Claude-authored PRs in the range. It runs in a separate context from the
   ones that wrote them and records findings on the promotion PR. Under the
   narrow cut, this is the reduced stand-in for #3807's audit, and the
   release notes say so.
5. Steven's merge of each PR is the human acceptance on record. The release
   does not claim independent external review for those PRs.
