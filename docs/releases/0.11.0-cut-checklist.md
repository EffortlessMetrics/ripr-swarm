# RIPR 0.11.0 cut checklist

Status: **draft, rebound 2026-09-22 to the #3921 release graph.** This is an
index over the issues that own each 0.11.0 step, in execution order. The
issues are the authority for scope, commands, receipts and prohibitions. This
file adds only the operator notes they do not carry: lessons from the trial
join, known defects, and the review-gap record. Where this file and an owning
issue disagree, the issue wins, and this file is wrong.

An issue's open or closed state is not proof. Each step names the receipt that
proves it, and the next step consumes that receipt, not the issue state
(#3921 control 6).

Nothing here authorizes a merge outside the named steps, a candidate ref,
a tag, a release, a registry upload, a marketplace publish, a secret, or a
settings change. Stable channels are authorized only on
[ripr#1470](https://github.com/EffortlessMetrics/ripr/issues/1470).

**Actors.** **Agent** means a Claude session. Recorded delegation:
- Steven's comments of 2026-09-17 on #2379 and ripr#1470: agents perform the
  authorized channel leaves and normal PR merges.
- Steven's project direction of 2026-09-22: an agent performs the
  history-preserving J merge itself.

**Steven** means an owner action that nobody else takes. Where an issue does
not name the actor, this file says so.

## 11. Recording the external-review gap

CodeRabbit posts a `success` status on Claude-authored PRs while skipping
them ("Review skipped: bot user not eligible for review"). `droid-review`
runs only on the self-hosted `em-ci-review` group, so it does not run while
that group is idle. Repository rules treat skipped or unavailable review as
missing review; see `docs/LEARNINGS.md`, "CodeRabbit Silence Is Not
Approval".

1. `@coderabbitai review` posted by `claude[bot]` did not start a review on
   #3884 or ripr#1774 on 2026-09-22. It has not been tried with the command
   posted by a human.
2. The #1772 PR body lists every Claude-authored PR in the promoted range that
   has no external review at its merged head, with `external_review:
   missing`. For each one it names the evidence that does exist: the
   exact-head `review-pr` COMMENT review, the `ub-review` decision,
   `droid-review` if it ran, and the required checks. A green CodeRabbit
   status is never counted as a review.
3. The #3807 final audit is the release's combined review of that range.
4. Steven's merge of each PR is the human acceptance on record. The release
   does not claim independent external review for those PRs.
