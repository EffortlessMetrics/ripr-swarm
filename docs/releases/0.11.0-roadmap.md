# RIPR 0.11.0 execution roadmap

Status: **active, written 2026-10-21 from `ripr-swarm/main` at `4d91ae82`.**
It ranks the work that has to land before the swarm hard cut. It is an
execution index, not authority: the linked issues own scope and acceptance, and
if this file and an issue disagree the issue wins.

Authority and sequence live elsewhere. [`#2379`](https://github.com/EffortlessMetrics/ripr-swarm/issues/2379)
is the release transaction, [`0.11.0-cut-checklist.md`](0.11.0-cut-checklist.md)
is the operator checklist, and [`#9271`](https://github.com/EffortlessMetrics/ripr-swarm/issues/9271)
tracks this roadmap. Nothing here selects a candidate, freezes a denominator, or
authorizes a merge, ref, tag or publication.

Timing (maintainer, 2026-10-21): the cut lands within about 400 PRs, roughly
Oct 21 to 22 and flexible. The candidate is a direct cut of accepted `main`
([`#1609`](https://github.com/EffortlessMetrics/ripr-swarm/issues/1609)), so
every merge until then is in the denominator.

## How to claim a piece

Claim a child issue with one ordinary comment (branch, PR, candidate state). It
is live for 3 hours of claimant activity and then takeable with a note. One PR
per claim. Each child below lists PR-sized pieces with acceptance criteria and
dependencies; take the earliest unclaimed piece whose dependencies are met.

## After the cut

These are not pre-cut work; they are listed so the cut is not mistaken for the
release. Per #2379: the #1609 candidate ref and manifest, then
[`#2769`](https://github.com/EffortlessMetrics/ripr-swarm/issues/2769)
exact-candidate qualification (Windows packaged, wheelhouse, wheel, archive,
crash and hang [`#4505`](https://github.com/EffortlessMetrics/ripr-swarm/issues/4505),
blind installed-agent journeys), the history-preserving source sync
`ripr#1768` to `ripr#1773`, the source release tail, public RC, stable decision
and the K back-sync. Each irreversible step needs its own explicit
authorization. `first-run-archive` is a post-publication check: it installs a
public release (default 0.10.0, the current release), so it cannot exercise
0.11.0 before an RC exists.
