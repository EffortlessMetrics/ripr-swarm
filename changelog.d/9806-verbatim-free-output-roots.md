- On Windows, `root` in SARIF refusal properties, limited and refused check JSON, and `ripr_diff` JSON now prints the plain drive-letter spelling instead of the `//?/` verbatim form, matching check JSON. The same applies to the `ripr check --root` restart route in triage, to seam-packet currentness reasons, and to agent and check diagnostics on stderr. On Unix the diagnostics are unchanged. The JSON root fields now use the stable check-JSON spelling, so a root containing `%`, `\` or non-UTF-8 bytes is percent-encoded the same way check JSON does it (#9806).
