- A test that calls the changed function only through a simple local alias (`let from_isoywd = NaiveDate::from_isoywd_opt; from_isoywd(..)`) is now linked as a call to the aliased function. The alias must be a single immutable, qualified `let NAME = path::to::function;` (not inside a macro) whose every other mention is a direct call after the binding; reassigned, shadowed, typed, passed-along or otherwise ambiguous aliases add no link. This adds reach evidence only and never strengthens an oracle (#8999). The alias call is recorded as the aliased path call (`Type::function(args)`) from the call's own bytes, so argument and free-function readers behave as if the path had been spelled directly.
