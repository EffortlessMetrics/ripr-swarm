- A TypeScript or JavaScript test that pins the changed boundary of a class method now reads `exposed` when it calls the method on an instance (`new Cart().discount(100)`, or a local `const cart = new Cart()` that is never rebound), through a renamed or barrel class import, or on the class itself for a static method (`Cart.discount(100)`). It read `weakly_exposed` before. The receivers are the ones that link the test to the method, so a same-named method on another object or class, and a method the test rebinds, replaces, spies on or mocks, still do not count (#16482).
