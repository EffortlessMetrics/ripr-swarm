- A TypeScript test file that holds one assertion under a condition static analysis cannot evaluate (for example `if (customSplitters) { expect(...) }` in one table-driven test) no longer marks every finding that merely reads a different test of that file as analysis-incomplete. The `unevaluated_condition` limitation now follows the tests a finding actually consulted, so those findings keep their gap-bound `ripr agent repair --gap-id` start, while a finding that rests on the conditional test, or a branch no registered test encloses, still reports the limitation and withholds the start (#11196).
