- MCP: a failed `ripr_refresh` no longer tells the agent to retry when a retry cannot succeed. A deleted repository root now says to restart with a valid `--root`, a missing-merge-base failure on a shallow clone says to fetch history first (other failures on a shallow clone still retry), an oversized diff scope (`diff_scope_oversized`) says to pick a nearer base, and `ripr_list_repair_attempts` on a deleted root answers `workspace_unavailable` instead of `attempt_invalid` (#15321).
