- MCP: a failed `ripr_refresh` no longer tells the agent to retry when a retry cannot succeed. A deleted repository root now says not to retry but to restart with a valid `--root` for any failure the analysis reports (configuration refusals raised before the analysis starts, such as an invalid `ripr.toml` or `RIPR_GIT_TIMEOUT`, keep their own recovery), a missing-merge-base failure on a shallow clone says to fetch history first with the root quoted as one shell argument (other failures on a shallow clone still retry), an oversized diff scope (`diff_scope_oversized`) says not to repeat the call but to pick a nearer base after the current merge base or raise the named limit, and the structured `remedy.retry_stated` of both no-retry recoveries is `false`, and `ripr_list_repair_attempts` on a deleted root answers `workspace_unavailable` instead of `attempt_invalid` (#15321).
