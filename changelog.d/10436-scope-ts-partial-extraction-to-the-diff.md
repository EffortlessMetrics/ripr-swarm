- The TypeScript `typescript_test_extraction_partial` disclosure is scoped to test files that can reach the diff. A dropped registration in a test file whose local import closure never reaches a changed file or names a changed owner no longer marks the analysis partial. An import the scan cannot follow (an unresolved relative import, a computed `import()` / `require()`, a path alias or workspace-package specifier, a bundler alias config, `import.meta.glob`) keeps the disclosure, as does a Rust change related to TypeScript tests through the Bun bridge.
