- `ripr agent stub` now names the repair journey the stub feeds (#8727). The `rust_test_stub` document (schema `0.3`, additive on `0.2`) may carry a `next_repair` block with the `ripr agent repair --seam-id <id> --phase before` start command and the repair packet's admitted `allowed_edit_surface`; when the stub's placement differs from that surface, `placement_divergence` names both files at generation time instead of failing later at the repair before phase's dirty-premise gate. Human output prints `Next repair:` after the Write/Run it lines plus the divergence warning. The block appears only when the seam's classified entry establishes the repair route (the pilot's fail-closed eligibility flip) and is omitted entirely — no invented route — when it cannot, notably for `--at --kind` file-parse selections. Divergent `--write --json` returns a versioned `placement_divergence` refused envelope on stderr with exit 2, preserving source/test bytes and metadata; cold analysis may populate its normal cache. See RIPR-SPEC-0287.
