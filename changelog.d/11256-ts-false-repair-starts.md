- TypeScript/JavaScript preview: three kinds of finding no longer offer a repair start the existing test already answers or that names the wrong discriminator (#11256). `toMatchObject` with a scalar literal (`expect(snakeCase("FooBarBaz")).toMatchObject("foo_bar_baz")`) is no longer called "assertion too weak": Vitest compares it for plain equality and Jest rejects it, so it reads `unknown` and names `typescript_match_object_scalar_unresolved`; object and array expectations keep their grade. A quoted operand is no longer cut at an embedded `-` or space (`arg !== "--"` named `arg == "`), and a condition holding two comparisons (`type !== "boolean" && typeof value === "string"`) no longer names the unchanged one. In each case no start is offered. The shared packet validator is unchanged.
