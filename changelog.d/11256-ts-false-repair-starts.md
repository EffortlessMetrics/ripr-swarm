- TypeScript/JavaScript preview: three kinds of finding no longer offer a repair start the existing test may already answer or that names an unfaithful discriminator (#11256). `toMatchObject` with a scalar literal (`expect(snakeCase("FooBarBaz")).toMatchObject("foo_bar_baz")`) is no longer called "assertion too weak": Vitest compares it for plain equality and Jest rejects it, so it reads `unknown` and names `typescript_match_object_scalar_unresolved`; object and array expectations keep their grade. A quoted operand is no longer cut at an embedded `-` or space (`arg !== "--"` named `arg == "`). A predicate on a local the owner computes from a call that names no parameter (`const type = getType(key); if (type !== "boolean" && ...)`) names `typescript_boundary_operand_derived_unresolved`, since no test call can set it. The shared packet validator is unchanged.
