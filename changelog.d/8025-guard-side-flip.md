- A changed `Err` guard (`if len >= 256 { return Err(..); }`) no longer reads as a weak-oracle gap when one test asserts the owner returns `Err` on the guard's edge input and `Ok` on the adjacent input (`assert!(check(256).is_err()); assert!(check(255).is_ok());`): moving the edge either way flips a side that test observes (RIPR-SPEC-0227 rule 3). The guard must be the owner's first statement and compare an integer parameter with an integer literal, and the rest of the owner can only return `Ok`. An oracle on one side only, far inputs, sides split across tests and a changed error keep the gap (#8025).
