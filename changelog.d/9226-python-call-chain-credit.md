- Python: a change to a one-`return` function or method that tests reach only through other one-`return` callers is no longer a silent `no_static_path` when a test pins the chain exactly. For example, `Ledger._ledger_pad` is reached only by `Ledger().render_ledger() == "|  |"`, or `post("ok") == "OK"` builds `PreparedRequest()` itself. ripr now evaluates the chain with the old and the new body, and credits `exposed` only when the pinned assertion holds before the edit and fails after it. Classes with bases, `__init__` or class state, decorated or patched callables, conditional assertions and tests that request fixtures keep their previous verdict (#9226).
