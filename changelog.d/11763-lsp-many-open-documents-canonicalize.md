- `ripr lsp` no longer canonicalizes the workspace root once per open document on every refresh, and on Linux (other Unix except macOS) it canonicalizes each directory once per refresh instead of every open file. Nothing is cached across refreshes, so a changed symlink is still seen. macOS and Windows keep the per-file resolution and gain only the single root resolution, so many-document refreshes stay slower there. The cost per refresh is still linear in open documents, so very large numbers of open documents remain superlinear overall (#11763).
