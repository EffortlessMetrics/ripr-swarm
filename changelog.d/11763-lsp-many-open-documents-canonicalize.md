- `ripr lsp` resolves the workspace root once, not once per open document, when it projects open-document paths, checks diagnostic containment and indexes diagnostic URIs on each refresh. On Linux (other Unix except macOS) it also resolves each directory once per refresh instead of every open file. Nothing is cached across refreshes, so a changed symlink is still seen. macOS and Windows keep the per-file resolution and gain only the single root resolution, so many-document refreshes stay slower there. The cost per refresh is still linear in open documents, so very large numbers of open documents remain superlinear overall (#11763).
