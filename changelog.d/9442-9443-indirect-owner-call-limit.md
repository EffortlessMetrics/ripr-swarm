- An owner a test reaches without a call ripr can place no longer reads as a weak gap: a path value or `fn` pointer binding (`.map(inc)`), an owner generated by an item macro, and an owner called inside `block_on` or a local `Future`-polling helper now read `static_unknown` under the new `rust_indirect_owner_call_unresolved` limit. `#[cfg_attr(all(), test)]` is read as an ordinary test, and a comment after the owner's tail no longer defeats the owner-return pin, so those cases credit. Nothing else moves in the Rust verdict corpus (RIPR-SPEC-0240, #9442, #9443).
