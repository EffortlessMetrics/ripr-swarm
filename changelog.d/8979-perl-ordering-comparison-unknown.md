- A Perl change to an ordering comparison (`<`, `>`, `<=`, `>=`, `lt`, `gt`, `le`, `ge`, `<=>`, `cmp`) no longer reads `exposed` just because an exact assertion names the same expression: that assertion may use inputs far from the threshold. It now reads `exposed` only when the assertion's owner call passes the threshold literal, and otherwise `static_unknown` with no repair gap and a next step that says what settles it. Equality tests and comparison-free sinks keep their alignment. A test that reaches the boundary only through non-literal inputs reads `limited` until the fact producer emits a row-owned predicate-input fact (#8979).
