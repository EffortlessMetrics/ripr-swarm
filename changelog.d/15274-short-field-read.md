- A changed field whose name is one or two characters long (`y`, `id`) can now be confirmed by a test. `Point { x: dx, y: 0 }` changed to `y: 1` with `assert_eq!(origin_shift(3).y, 1)` used to read `weakly_exposed` with `observation_unconfirmed` for both the `field_construction` and the `return_value` finding, because a name that short is never matched as a token, so no assertion could ever confirm it and `verify` stayed refused. A `.y` read on the owner's own result, called directly or bound with `let`, now confirms the field and both findings read `exposed`, as a read of a longer name (`.retries`) already did. A read of another field (`.x`), of the same name on another value, or one copied into the expected side still confirms nothing (#15274).
