- `ripr agent repair` refusals for a wrong attempt selection now name the fix. An unknown `--attempt` says to check the ID and `--store`, and still ends with the `ripr agent status` command bound to the same `--root` and `--store`. An attempt from another repository says to run from (or select) the repository it started in. A repository with no commit says to commit once before starting an attempt; a committed checkout whose HEAD ripr cannot use keeps Git's diagnosis instead. Library and MCP callers that reach the selector checks without the CLI's own flag validation now hear which flag to pass for a missing selector or an empty seam ID (#16019).
