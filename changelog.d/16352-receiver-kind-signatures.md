- A Rust method whose receiver is written with its type (`self: &Self`, `self: &mut Self`, `self: Self`) or whose generic bound has parentheses (`fn map<F: FnMut(&u32) -> u32>(&self, f: F)`) now has its receiver read like `&self`, `&mut self` or `self`. Before, such a method read as having no known receiver, so a same-named inherent method or an earlier standard trait method that takes `value.name()` first did not withdraw a trait impl method's direct-call credit; the test is now related by name only in those cases. Smart-pointer receivers such as `self: Box<Self>` are still not read (#16352).
