- The non-plain `Drop` demotion for an owner return now scans only exit positions: a record constructed only in a local, non-returned position (such as a let-bound guard) no longer demotes the finding to `weakly_exposed`, because that value drops inside the owner rather than while unwinding from a failed assertion. Records in the block tail, a `return` value, branch or match-arm tails feeding the result, records a returned binding names, and records wrapped in exit position still demote, and any shape that cannot be placed confidently in a non-exit position still demotes (#8480, RIPR-SPEC-0197).
