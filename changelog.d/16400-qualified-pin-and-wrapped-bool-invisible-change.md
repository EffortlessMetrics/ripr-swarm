- A Rust test that cannot tell the changed function from its previous version no longer reads `exposed` in two more shapes: a path-qualified pin on a value neither version returns, such as `assert_eq!(mycrate::fee(4), 99)`, and a boolean wrapped in `Some(..)`, `Ok(..)` or `Err(..)` that is the same at the asserted input, such as `Some(x >= 0)` changed to `Some(x > 0)` with only `assert!(matches!(check(5), Some(true)))`. Both now read `weakly_exposed`; a test at an input that separates the versions keeps `exposed` ([#16400](https://github.com/EffortlessMetrics/ripr-swarm/issues/16400)).
