- A test that binds `let s: Box<dyn Shape> = Box::new(Square(3));` and asserts on `s.area()` now credits the change to `impl Shape for Square`, or to a `Shape` default that `Square` does not override, as `exposed`, the same as `Square(3).area()`. Before, it read name-only (`reachable_unrevealed`) or `weakly_exposed`. Only the trait in the `dyn` annotation counts, so an inherent method or another boxed type is never credited. A trait with generics, supertraits or a `where` clause, and a method name that `Box` itself answers (`as_ref`, `deref`, `clone`, ..), keep their old reading (#15277).
