- A Rust helper wrapper that uses a bare `anyhow!` or `json!` now forwards its helper result when the macro comes from a rootless grouped import (`use {anyhow::anyhow, std::path::Path};`). Each item in the group is now checked against its own crate root, at the same audited release as a plain import. Before this fix, the boundary test of such a wrapper read `propagation_unknown` instead of `exposed`. A macro name that appears only in a string, a comment or a longer identifier (`println!("anyhow error")`) also no longer withholds credit when a same-named macro is defined or imported elsewhere. Only a bare invocation of the macro reads that rebinding (#16388).
