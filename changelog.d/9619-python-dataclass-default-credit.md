- Python edits that replace a numeric default of a plain `@dataclass` field are now credited to a test that omits the field and asserts an exact numeric result the method computes from it: RIPR evaluates the method under the old and the new default and credits only an assertion that held before and fails after. An explicit rate, a `frozen`/`init`/`kw_only` option, a base class, a `__post_init__` or other generated-method hook, a method outside `+ - * /` and `round`, or a default change that rounds to the same result keep the `decorator_indirection` abstention (#9619).
