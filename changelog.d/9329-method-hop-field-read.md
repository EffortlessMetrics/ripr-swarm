<!-- section: Changed -->
- A helper chain can now cross a receiver call on a typed parameter (`b.to_string_as(si)` into a unique inherent `&self` method) and read a tuple-struct field of the receiver (`self.0`) from a test argument written as `Type(<literals>)` or a `const fn` constructor over literals and same-file constants, so the boundary row is read (infection `yes`) instead of `infection_unknown`. An owner with several direct callers (a `Display::fmt` beside `to_string_as`) binds through the one caller a test reaches and declines when none, two or a calling test reach it. A test helper whose only statement is an `assert_eq!` on the method call's result, over methods that hand the owner's result back unchanged, pairs its exact pin with the boundary row, so the bytesize shape reads `exposed`; a helper that drops, reshapes or shadows the result still abstains. A free-function owner's name on a receiver call (`expected.to_string()`) no longer makes the expected side "computed through the owner". A receiver that is not a typed parameter, is rebound, or is built any other way keeps the earlier stop (#9329).
- A helper chain whose callee has several direct callers now binds through the one caller a test reaches instead of stopping at "N callers"; it still declines when no caller or two callers are reached, when a test calls the callee directly, or when there are more than eight callers. A caller that only makes receiver calls (`x.name()`) no longer counts as a caller of a free function (#9329).
