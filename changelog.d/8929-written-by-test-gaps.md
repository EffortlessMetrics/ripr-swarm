- Owner-pin no longer reads an expected value as unwritten when the test writes it through `&mut (name)`, a `ref mut` binding on it (`let ref mut r = name;`, `match name { ref mut r => .. }`, `if let Some(ref mut x) = name`), `addr_of_mut!(name)` / `ptr::addr_of_mut!(name)`, a path-qualified `&mut crate::name`, or an inner-block `static` that redeclares the name after a plain top-level `let`. It also stops refusing `foo(name)?;` and `foo(name).await?`, where a bare `?` or `.await` after a call group only reads the argument (#8929).
