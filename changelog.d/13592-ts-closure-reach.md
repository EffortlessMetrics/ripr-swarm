- TypeScript: code reached only through a closure (a function passed as a value such as `JSON.parse(text, reviver)` or `keys.sort(compare)`, a parser-combinator constant built by `match(re, (s) => ...)` and later invoked, or the combinator itself) is no longer reported `no_static_path` when a test calls the export that leads to it. It reads `static_unknown`, because when the value runs is not modeled. On the eight unjs packages of the TypeScript Stryker corpus, Stryker-caught mutants reported `no_static_path` fall from 723 to 428 and no other verdict changes (#13592).
