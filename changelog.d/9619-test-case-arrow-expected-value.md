- A `#[test_case(args => literal)]` row now credits like the `assert_eq!` the harness runs. The returned expression is compared with the literal, so `#[test_case(2 => 4)] fn squares(x: i64) -> i64 { square(x) }` pins `square`. Only a clean row is read: a plain literal after the arrow, scalar literal row arguments, a trusted `test_case` import and a body that is one returned expression. `=> matches`, `=> with`, `=> panics`, a computed expectation, `#[should_panic]`, `#[ignore]` and a statement-bearing body stay unread. Moves `lib-test-case-arrow-expected-value` from limited to credited; no row turns false (RIPR-SPEC-0231 rule 9, #9619).
