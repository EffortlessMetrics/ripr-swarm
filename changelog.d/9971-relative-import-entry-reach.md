- A unit test under `src/` that imports the entry with a relative path (`use super::entry;`, `use super::super::entry;`, `use super::module::entry;` or `use self::module::entry;`) is now related to the entry's changed private helper when the path provably resolves to the module that declares the entry. It stays unrelated when the test module is declared under a `cfg` other than a bare `#[cfg(test)]`, when the package has any `#[path]` remap, when the test file has an inline module, glob import, `cfg`-gated `use`, macro definition or item-position macro, when a nearer local binding shadows the name, or when the path resolves to another module, a re-export or a member crate's same-named module (#9971).
