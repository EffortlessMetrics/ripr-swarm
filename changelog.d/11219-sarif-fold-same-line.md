- Findings SARIF now reports one result per changed line and class: two probes of the same class on one line (for example an `error_path` and a `return_value` probe) fold into one result, the one with the smallest fingerprint, which keeps its message and fingerprint and lists the others in `properties.folded_results`; the run records `folded_same_line_results`. Code scanning opens one alert for the edit instead of several. After upgrading, existing alerts and baseline entries for the folded probes close once (their fingerprints no longer appear); the kept alert is unchanged. Different classes, different suppression state and results without a line stay separate (#11219).
