- The `rust_log_capture_unresolved` limit now binds to the changed record's own format template. A record with a `target:` or `key = value;` prefix (or a comment or character literal among its arguments) reads its real template, the template's static text must appear in order inside one string literal of the assertion, and a template whose static text has no letters or digits (`"{}: {}"`) keeps the gap, so an assertion on a different record of the same owner no longer withholds the finding through these routes. A template that starts or ends with static text must start or end the asserted literal (`"audited {}"` no longer binds `"unaudited 42"`), escapes compare as decoded text (a template or literal with an escape other than `\n`, `\t`, `\r`, `\0`, `\\`, `\"` or `\'` is not bound), and an asserted raw literal binds like the cooked literal of the same text. A template that uses one named or positional argument twice is not bound, and a `format!` template in the assertion is not asserted text. A literal inside a comment, nested block comments included, never counts as asserted text (#7133).
