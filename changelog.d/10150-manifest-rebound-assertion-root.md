- A Rust test whose `std::assert_eq!` or `core::assert_eq!` names a crate root that the test's own `Cargo.toml` binds to another package (`std = { package = "..." }` in a `#![no_std]` crate, or a `core` dependency) no longer gives a constructor called inside the assertion `strongly_gripped` exact-value credit. The assertion now reads as an `unknown` oracle, because the substituted package may or may not check anything. The same test without the rename keeps its credit, and so does one where the name appears only in `[build-dependencies]`, in a `[patch]`, or in the manifest of another package beside an included test file (#10150).
