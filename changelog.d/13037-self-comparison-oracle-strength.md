- A related assertion that compares a value with a copy of itself (`assert_eq!(b.0, b.0.clone())`) no longer reports a `strong` oracle. It passes for any value with ordinary equality, so ripr no longer credits it as a discriminator: its strength relative to the finding is `weak` and it never confirms observation, like a self-computed expected value. This is conservative for a NaN-capable float or a hand-written `PartialEq` (#16227). A hand-written `Clone::clone` pinned through a derived `PartialEq` keeps its credit (#13037). Such a row now says that static analysis did not establish that it discriminates the changed behavior, instead of calling the assertion too weak, and its next step is to verify the changed behavior or assert against an independent expected value.
