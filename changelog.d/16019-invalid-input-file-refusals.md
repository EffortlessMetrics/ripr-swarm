- **CLI:** Input files that parse but do not hold what a command reads now name the command that writes a usable one. `ripr review-comments --check-output` says to rerun `ripr check --json`, `ripr swarm queue --gap-ledger` and `ripr agent packet --gap-ledger` say to regenerate the ledger with `ripr reports gap-ledger`, and `ripr receipt check` says to rewrite a malformed receipt with `ripr receipt write` or to pass the ledger `ripr reports gap-ledger` wrote. `ripr receipt write` outside a Git checkout with a commit says to run from inside one.
