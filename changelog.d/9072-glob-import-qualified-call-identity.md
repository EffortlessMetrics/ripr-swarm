- A Rust integration test that opens with `use <crate>::*;` no longer makes a call of one module's function (`b::render(..)` or `mycrate::b::render(..)`) read as a test of a same-named function in another module. The glob used to leave every qualified call unsettled, so a change to `a::render` was credited to a test that only calls `b::render` (`weakly_exposed` with a misdirected next step instead of `no_static_path`). A glob of the owner's own crate now resolves to that crate's placed modules; a dependency's glob still leaves the call unsettled (#9072).
