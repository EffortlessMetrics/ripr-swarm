- A TypeScript getter changed inside a class is no longer reported `no_static_path` when a test reads it on an instance built by an exported factory of that class (`const box = cached(() => 1)` then `expect(box.value).toBe(1)`, as in colinhacks/zod's `Cached.value`). The factory must provably return `new Class(...)` of the getter's own class on every path, the receiver must be bound once and never rewritten, and the test must not spy on, redefine or mock the getter, the factory or the module; any such shape stays `no_static_path`. The finding now reads reach `yes`, and factory reach alone never promotes it to `exposed` (#10402).
