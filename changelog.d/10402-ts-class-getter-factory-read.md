- A TypeScript getter changed inside a class is no longer reported `no_static_path` when a test reads it on an instance built by an exported factory of that class (`const box = cached(() => 1)` then `expect(box.value).toBe(1)`, as in colinhacks/zod's `Cached.value`). The factory must return `new Class(...)` of the getter's own class on every path, the class and its same-file ancestors must be unable to replace the getter, the receiver must be bound once, never rewritten, scoped to its block and be the subject of an `expect(...)`, and nothing in the test file may spy on, mock, redefine or assign the getter or the factory; any such shape stays `no_static_path`. The finding now reads reach `yes`, and its class is decided exactly as for a test that constructs the class directly (#10402).
