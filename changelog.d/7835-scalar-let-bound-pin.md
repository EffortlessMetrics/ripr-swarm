- A test that binds a primitive owner result once and reads it in another assertion before pinning it (`let b = bonus(4); assert!(b > 3); assert_eq!(b, 12);`) now credits the exact assertion as an owner-return pin. Before, it read `weakly_exposed`. A `bool`, `char`, float or built-in integer result cannot change after an immutable `let`. Non-scalar results keep the rule that only an assertion right after the `let` pins. A result whose type name the owner's file shadows, or any use of the binding outside a plain `assert!`/`assert_eq!`/`assert_ne!`, still refuses (#7835).
