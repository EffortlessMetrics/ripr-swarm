- `ripr agent repair --phase after --test-result <file>` validates and records a caller-reported focused `cargo test` result: it must be bound to the attempt and the evaluated HEAD, name the selected test file, include at least one test that ran in that file or inline module, and carry no failure the file does not explain. It checks binding and per-test outcomes only, not stream completeness (a test reporting both `ok` and `failed`, a `started` test with no terminal event, or a missing suite event are not yet refused). It is optional for existing-test attempts and required for new-test proposal attempts; ripr never runs or observes the tests (#13203).
