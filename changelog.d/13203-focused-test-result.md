- `ripr agent repair --phase after --test-result <file>` validates and records a caller-reported focused `cargo test` result: it must be bound to the attempt and the evaluated HEAD, name the selected test file, include at least one test that ran in that file or inline module, and carry no failure the file does not explain. It is optional and does not yet gate finish; ripr never runs or observes the tests (#13203).
