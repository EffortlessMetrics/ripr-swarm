- `pr-comments existing --raw -`, the `pr-comments requests|summary` manifests and request files, and the `reports ci-packet` `pr.diff`, receipt, labels, stage-redirect and artifact-copy writes now go through the symlink-refusing advisory writer instead of plain `fs::write`/`fs::copy`, so a planted leaf link is refused rather than followed. The default-output containment guard now also checks every direct child of `target/ripr` (for example `review`), and `review-comments`, `gate evaluate` and `pr-comments` call it, so a committed `target` or `target/ripr/review` link that escapes the workspace is refused. An explicit `RIPR_CACHE_DIR` still skips the whole guard (#4360, #7781).
