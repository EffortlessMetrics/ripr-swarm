- `assert_ne`, `debug_assert_eq`, `debug_assert_ne`, `assert` and `debug_assert` (bare or `std::`-qualified) now pass the same execution admission as `assert_eq` for side-effect findings, and the equality forms for return-value findings: an assertion that cannot run (after a `return`, in an uncalled function or closure, a false `if`, an impossible match arm, `cfg!(any())`) no longer credits the finding, and a dead sibling does not change a live assertion's credit. A boolean `assert!`/`debug_assert!` in a dead context can still credit a return-value finding (#10389) (#8983).
