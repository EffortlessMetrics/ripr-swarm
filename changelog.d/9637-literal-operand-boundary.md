- A changed boundary whose operand is computed from literal test inputs by exact integer arithmetic (`s.len() < 2 + 2`, `n % 2 == 1`) or by `str::len`, `split_whitespace().count()` or `chars().count()` now credits through an observed equality row instead of reading `infection_unknown`, as long as every operand is a literal text or integer argument, a same-file constant, or a plain `&str`/`String`/integer owner parameter that the owner never rebinds. These operations only credit: a computed or call-result argument, a generic or slice receiver, a test that lands on the wrong side of the boundary, or a rebound parameter stays unresolved and never names a missing input, and a weak oracle still reads `weakly_exposed` (#9637).
