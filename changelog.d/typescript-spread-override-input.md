- TypeScript: dropping or adding one literal field after a spread, such as `return { ...cfg, ok: true }` becoming `return { ...cfg }`, no longer reads `exposed` when every observed test input already carries `ok: true` or cannot be read. RIPR-SPEC-0246 rule 3 keeps the credit only when an observed input lacks the field or holds another value there, read inline, through a `const` binding (typed or not), or through a strong pin on that field such as `ready(cfg).ok`. An owner that writes to, or passes on, the spread parameter keeps the ladder verdict (#7963).
