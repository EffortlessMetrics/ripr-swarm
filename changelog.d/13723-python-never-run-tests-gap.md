- Python: a test that provably never runs (an unconditional `@pytest.mark.skip` or `@unittest.skip`, a module-level `pytest.skip(..., allow_module_level=True)`, an empty parametrize table, a parametrize mark pytest refuses, a replaced definition with no alias, or a class `__test__ = False`) is now reported as a gap that names the dead test, instead of an "activation unestablished" abstention. Conditional skips, `xfail`, `importorskip`, module `pytestmark`/`__test__`, classes with a base outside the file, and project collection rules still abstain (#13723).
