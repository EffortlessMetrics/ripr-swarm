- Editing one arm of a one-line tail `if` now probes that arm. `if x % 2 == 0 { Some(x) } else { Some(0) }` changed to `{ None }` used to report `infection_unknown` with a probe on the unchanged `Some(0)` arm, so `assert_eq!(find_even(4), None)` could never confirm the edit. The probe now sits on the changed arm with the old value as its "before", and that test makes the finding `exposed`. A test of the other arm stays `weakly_exposed`, as does an edit whose new value also appears elsewhere on the line (`{ None } else { None }`), which cannot be told apart from its twin. Condition edits, swapped arms and `else if` chains keep their previous handling (#15274).
