- A test of a same-named function in another module no longer counts as a test of the changed function. `b::render(..)`, or a bare `delay(..)` that `use super::*` binds to a sibling file's own `delay`, now supplies no reach and no confirming tokens. This removes a false `exposed` (#6537) and a false grip (#6292) (#6867).
- A `use` import now settles which same-named function a bare call names, so `use super::celsius::snap;` with an exact `assert_eq!` reads `exposed` instead of a false `weakly_exposed`. The owner-return pin resolves the asserted call itself, and a call ripr cannot settle stays unsettled: a dependency's namesake path (`other_dep::a::render`), a module alias it cannot follow, a `use` inside a nested block, or a package that remaps module files with `#[path]` never credits the owner (#6544) (#6867).
