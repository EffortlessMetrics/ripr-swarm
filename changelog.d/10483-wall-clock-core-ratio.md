- Core complexity tests (diff run starts and long lines, path globs, suppression globs, error-return twin chains) compare the same work at two input sizes through `testing::scale::assert_growth_within` instead of asserting an absolute wall-clock bound, so a slow runner no longer fails them. The ratio rejects polynomial growth once the small run is above a 10 ms noise floor; a non-terminating regression still ends at the harness timeout. The check-budget deadline test now asserts the grace wait expired with the worker still parked, with a finite containment release, and pins the 2 s production grace (#10483).
