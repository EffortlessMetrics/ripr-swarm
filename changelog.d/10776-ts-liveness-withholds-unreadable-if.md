- TypeScript boundary liveness: a changed `if` statement that opens a brace and whose branch pair cannot be read (one-line `if (c) { return 1; }`, or nested in an arrow or `function`) now withholds boundary credit instead of leaving the witness standing, so a dead expected value on those shapes no longer reads as `exposed` (#10776). A changed ternary, `else if` head, brace-less one-line `if` or multi-line condition is unaffected. The withholding applies only after the existing gates (an owner body, a numeric expectation and a unique changed line).
