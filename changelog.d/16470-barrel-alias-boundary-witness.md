- A TypeScript or JavaScript test that pins the changed boundary now reads `exposed` when it calls the function through a barrel under another name (`import { discount as d } from '../src'`) or through a renamed re-export (`export { discount as applyDiscount } from './price'`). It read `weakly_exposed` before. A destructuring inside the test (`const { d } = helpers`, including a later declarator such as `const h = make(), { d } = h`) now hides such a name, so that test is no longer linked to the function. A call of the function nested inside another call under a renamed import (`expect(d(90, discount(100)))`) no longer counts as testing the boundary: only the outer call's result is checked (#16470).
