- A loop that adds a called function's value into a returned local is now read, including an `async` owner that awaits it: `for x in xs { t += double(*x).await * 1; }` is a `return_value` change, credited when an exact pin's literal run, folded through `double`, gives the pinned nonzero value and every neighbouring mutation (the opposite sign, `|=`, `^=`, overwriting, and the other `+ - * / %` for the term's operator) gives a different one. A callee ripr cannot evaluate, a one-element run, a run where two neighbours coincide and a fold that misses the pin stay `static_unknown`. Moves `shape-async-await-accumulate` from limited to credited; no row turns false (RIPR-SPEC-0360, #9478).
