- A `return_value` finding whose returned record type has a non-plain `Drop` impl in the workspace now demotes to `weakly_exposed` at the final semantic owner: dropping the returned value while unwinding from a failed assertion may exit the process before the failure is reported. The generic oracle path previously credited the whole-object equality assertion without consulting the owner return pin, so the return_value finding stayed `exposed` beside the correctly demoted field-construction finding. Plain (empty or comment-only) Drop bodies keep the finding `exposed` (#8480, RIPR-SPEC-0197).
