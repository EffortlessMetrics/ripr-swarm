- TypeScript and JavaScript preview findings for edits whose infection the adapter does not model (a literal return value, a `??` / `||` fallback literal, a default parameter, an identity operand such as `+ 0`, a comment-only edit) now read `infection_unknown` with an `infection_evidence_unknown` stop reason and no repair packet, instead of `weakly_exposed` decided by oracle strength alone. A non-predicate change under an `if` arm no related test enters now reads `reachable_unrevealed` with infection `no` instead of `weakly_exposed` with an "assertion too weak" explanation. Relational predicates, ternaries, `throw` paths and positive infection states remain follow-up work (#10704, #11034).
