- JSON refusals: `ripr receipt check --json` with a missing or malformed receipt or an unreadable `--ledger`, and `ripr cache status --json` with a `--root` that is not a directory, now write the `cli_refusal` document (new code `input_unusable`, help route as `next`) instead of leaving stdout empty; `ripr agent status --attempt nope --json` writes `invalid_value` with `next` set to `ripr agent status --root <root>`, the command that lists attempt IDs. An invalid `ripr.toml` under `--json` (`check`, `agent brief`, `rerun`, `context`) now carries the human next step in the refusal message and `remedy`, with `error.next` set to `ripr config validate --root <root>` on `check`, instead of ending at the TOML line/column with `next: null`. A `context --at` selector miss now carries the listing command its own message names as `error.next` (a seam-id miss stays `null`). Exit codes and stderr prose are unchanged (#15260).
