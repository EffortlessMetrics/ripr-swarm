- Mixed-quote Git rename headers no longer lose disclosure: with `core.quotePath=true` git quotes each `diff --git` path independently, so an ASCII-to-Unicode rename arrives as `a/src/lib.rs "b/src/日本語.rs"`. The old-path reader now recognizes the independently quoted destination boundary instead of assuming symmetric quoting; previously the rename pair failed to validate, the renamed file vanished from scope, and a separately parseable file (for example a `Cargo.toml` path edit) masked the missing scope with a complete-looking result. Pure mixed-quote renames are counted and disclosed without invented probes, and an isolated pure-rename section is disclosed instead of refused as `malformed_diff`; edited mixed-quote renames keep their findings under the decoded new path with the existing old-path-association limitation. Confinement, adversarial-path controls, and the loader's `core.quotePath=true` pin are unchanged (#7795).
