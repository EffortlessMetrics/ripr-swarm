- A call edited only in a `std::sync::atomic::Ordering` argument (for example `compare_exchange(.., Ordering::AcqRel, ..)` to `Ordering::Release`) is now seeded as `static_unknown` instead of `call_deletion`, so a strong value or whole-object oracle on the reached function can no longer report it `exposed`: no assertion on a returned value can observe a memory-ordering edit. Edits that also change a value argument, and bare or non-atomic enum variants, keep their delivered family (#9080).
