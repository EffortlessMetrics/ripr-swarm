- A call edited only in a `std::sync::atomic::Ordering` argument (for example `compare_exchange(.., Ordering::AcqRel, ..)` to `Ordering::Release`) is now seeded as `static_unknown` instead of `call_deletion`, so a strong value or whole-object oracle on the reached function can no longer report it `exposed`: no assertion on a returned value can observe a memory-ordering edit. Only call and side-effect probes are demoted, and only for bare or `atomic::`-qualified `Ordering` variants with no string, char or comment on the line; edits that also change a value argument, `cmp::Ordering` and other enums keep their delivered family (#9080).
