The first snapshot commit retracts the marker with the established empty clear (re-serving the committed baseline when the plan suppressed an unchanged payload), a latched config failure withdraws already-published diagnostics with the `withdrawn_configuration_failure` marker, and root transitions, shutdown, and document close retract or drop it (#8732).
