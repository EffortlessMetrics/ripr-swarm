- A changed Rust field assignment (`self.count += 1`, `self.state = State::Done`) gets a field probe instead of `static_unknown`. It is credited when an `assert_eq!` reads that whole field, directly or through a plain getter, from the binding the test called the owner on. When no related test asserts anything, it reads `reachable_unrevealed`. Any other reading still abstains, and assignments spanning lines, calling a function or choosing between values keep their earlier probes.
