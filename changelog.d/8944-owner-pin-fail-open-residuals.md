- Owner-pin no longer reads an expected value as unwritten when the test borrows or binds it mutably through a raw identifier (`&mut r#name`, `addr_of_mut!(r#name)`), a dereference (`&mut *name`, `addr_of_mut!(*name)`, `let ref mut r = *name;`), a `ref mut` in a tuple or block scrutinee (`let (a, ref mut b) = (x, name);`, `match (x, name) { (_, ref mut r) => .. }`, `let ref mut r = {name};`), an annotated `let ref mut r: Vec<u8>= name;`, or a borrow of a block, tuple, array or generic/turbofish path (`&mut {name}`, `&mut (x, name)`, `&mut <T>::name`, `&mut m::<T>::name`). A `ref mut` in an earlier statement (`let ref mut r = other; v = name;`) no longer refuses a later `name` (#8944).
