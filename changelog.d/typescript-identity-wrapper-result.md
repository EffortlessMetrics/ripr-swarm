- TypeScript `toBeInstanceOf` class pins and `toMatchObject` field pins now credit a pin on `wrap(owner(...))` when `wrap` is a test-local identity helper: a top-level, unexported `function wrap(p) { return p; }` or `const wrap = (p) => p;` whose name the test file uses only as a direct call, called with the owner call as its one argument. A helper that transforms its argument, or one that is reassigned, shadowed, exported or overloaded, keeps the weak reading. Both pins also stop crediting `ns.owner(...)` when the test body rebinds the namespace import `ns` (RIPR-SPEC-0249, RIPR-SPEC-0250, #8092).
