- A `&mut self` method that assigns a field (`self.n = 1`) now reads `exposed` when a test calls it on a receiver and then asserts that receiver's field exactly (`c.reset(); assert_eq!(c.n, 1);`), instead of `reachable_unrevealed` or `static_unknown`. The receiver may be built as a crate-qualified struct literal through the package's own unshadowed library name (`let mut c = krate::Counter { n: 5 };`), and the field name no longer has to be long enough to count as a token match; a read of another binding or field, a rewrite or rebinding before the read, or a foreign or locally shadowed crate name still keeps the gap open (#14407).
