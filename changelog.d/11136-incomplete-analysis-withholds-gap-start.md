- `ripr check` no longer prints a gap-bound `ripr agent repair --gap-id` start for a TypeScript finding while its own analysis is incomplete (for example a credited assertion under a condition static analysis cannot evaluate): the after phase refuses such a before artifact, so the start could not finish. The start now uses the same completeness predicate as the verify and after phases and instead says the analysis is incomplete, naming the limitation and its recovery. When the after phase does refuse an incomplete or bounded artifact, the message names the limitation and the next step rather than "regenerate it", which reproduced the same artifact (#11136).
