- The default in-file unit-test layout, `#[cfg(test)] mod tests { use super::entry; .. }` beside the entry, again relates the test to the entry's changed private helper. Since the relative-import refusal (#9914, #10128) the inline test module was refused outright and the test fell to proximity-only weak reach. Each relative `use` is now resolved from the inline modules around it and credited only when it names the entry's own module and sits in the test's own module; a `super` that names another inline module, goes past the crate root, sits only in a sibling module, or sits beside a glob, a `cfg`-gated `use` or a nearer binding stays refused (#10279).
