- TypeScript preview now reads the condition of a ternary in a declared concise arrow (`export const f = (n) => n > 100 ? a : b`, `=> (n > 100 ? a : b)`) and of a parenthesized return (`return (n > 100 ? a : b);`) as a predicate boundary. A test that calls both sides of the boundary reads `exposed` instead of `weakly_exposed`; a test that never reaches the boundary input stays `weakly_exposed`. A callback arrow inside a call, a block body and a bare comparison body are unchanged (#8464).
