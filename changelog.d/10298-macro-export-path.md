- A `macro_rules!` test generator marked `#[macro_export]` and named by `use crate::name;` now registers its tests when exactly one macro of that name exists in the file's crate. Before, a table invoked through such an import read as `no_static_path`. A second definition of the name, an export the scanner cannot list, renamed or grouped imports and cross-crate paths still index nothing (#10298).
