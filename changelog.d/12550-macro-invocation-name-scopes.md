- A macro-generated Rust test pinned to its macro invocation line now takes the name scopes (imports, module path) visible at that invocation, for an indented invocation too. Generated-versus-authored provenance travels on the test fact, so a same-name `fn` on the invocation line is never lent to a generated test, and invocation scopes are borrowed only when the invocation line holds exactly one item-position macro call and the expansion declares no `use` or item, binds no name outside a `let` (closure or function parameter, `for`, `if let`, `match` arm) and calls no macro other than a bare std expression macro such as `assert_eq!`; any other generated test takes no invocation scopes rather than risk crediting the wrong owner. The six `macro_export` verdict-corpus rows still read `limited`; they wait for call identity to consume the invocation-site scope (Advances #12320, #12550).
