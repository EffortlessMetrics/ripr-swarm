- A builder default the test overrides before asserting (`RetryBuilder::new().attempts(5).build()` then `assert_eq!(retry.attempts, 5)`) no longer reads `exposed`: a struct literal or field initializer whose only confirming token is a field the test overwrote on the owner's result, through a setter whose body plainly stores its argument, a `let` hop, a self-reassignment or a field assignment, now reads `weakly_exposed` with a named `observation_unverified` reason. Reading the default with no setter, a setter that adds or clamps, a setter on another field, a discarded setter result, a setter inside an argument and any later mutation of the binding keep the credit (#6613).
