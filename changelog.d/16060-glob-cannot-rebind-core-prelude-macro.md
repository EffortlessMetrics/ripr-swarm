- A glob import from another crate (`use rayon::prelude::*;`, `use rmcp::model::*;`) no longer leaves every plain `assert!`, `assert_eq!` or `assert_ne!` in its reach "not credited". rustc rejects a bare call whose name both a glob and the standard prelude supply, so a glob cannot silently replace those macros. It still blocks names it can bind, such as `vec!`, `format!` and the claims macros, and `#[no_implicit_prelude]`, explicit imports, local definitions and `#[macro_use]` keep their refusals (#16060). An item-position `include!` of a computed path (for example `include!(concat!(env!("OUT_DIR"), "/generated.rs"));`) now counts as a possible definition of every trusted macro, since the included file may define its own `assert_eq!`; the per-file facts cache moves to 1.66.
