- A return-value owner reached through bare free calls (`pub fn outer(x) -> i64 { inner(x) + 1 }`, `inner` private and declared beside it) is now pinned by an exact assertion on the entry, so an integration test asserting `outer(5) == 11` reads `exposed` instead of `propagation_unknown`. The entry may hand the owner's result on unchanged or shifted by an integer literal (`+ 1`, `1 +`, `- 1`) over builtin integer types. Other operators, casts, a non-literal operand, a swallowed or clamped result, float/string/custom types, imported, glob-imported, shadowed, parameter-named, cross-file or module-qualified callees keep the abstention (#9638).
