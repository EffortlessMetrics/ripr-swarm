- A TypeScript or JavaScript test that passes the changed boundary input to the function only inside a wrapper (`expect(Math.max(discount(100), 100)).toBe(100)`) or a nested call (`expect(discount(90, discount(100))).toBe(90)`) now reads `weakly_exposed` instead of `exposed`. Neither assertion observes the call that receives the boundary input: the wrapper can return the same value on both sides of the boundary, and the outer call's own input is off the boundary. A test that asserts the whole call (`expect(discount(100)).toBe(90)`) is unchanged (#16458).
