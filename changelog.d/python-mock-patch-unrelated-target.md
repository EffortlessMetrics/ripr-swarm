<!-- section: Changed -->
- Python: a related test that only patches a string-literal dotted target the owner's file never names (for example `@patch("os.getcwd")` against an owner that does not use `os`, `getcwd` or that module) no longer raises the `mocked_module` static limit (#9098). `patch.object`, `patch.multiple`, `patch.dict`, `monkeypatch.setitem`/`delattr`, object-form `monkeypatch.setattr`, non-literal, f-string or concatenated targets, bare `@patch`, and any target segment that appears anywhere in the owner's file keep the limit, as does a run without the owner's source, a test method (class-level `@patch` is not retained), and an owner that imports beyond a short list of self-contained standard-library modules or calls `super()`.
