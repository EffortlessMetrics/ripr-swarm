- An assertion inside `for x in [a, b, ..]` now counts as run when the array is non-empty and its rows only name values (literals, locals, `const`s or `static`s), not only when every row is a literal. Before, a table such as `for (input, before) in [(POW2, "..")]` was reported as "may run zero times". A row that calls code still refuses, since it could exit before the loop starts. An expected value taken from such rows is never credited, because a `const` may hold the function's own output (#14116).
