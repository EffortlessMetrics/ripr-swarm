- `ripr check` no longer re-masks and re-parses a parent module file for every related test of every probe when it checks whether a parent module shadows the receiver type or trait. The owner-independent part is answered once per file and name, so a warm check on a large crate does less repeated parsing (on this repository's `crates/ripr` diff, warm 120 s to 102 s with byte-identical reports) (#10809).
