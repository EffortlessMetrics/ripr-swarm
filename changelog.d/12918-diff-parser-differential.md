- Added a differential proptest that feeds real `git diff` output for generated edits (modify, rename, delete, new file, binary, CRLF, missing final newline, `-U0` to `-U5`) to the unified-diff parser and compares the changed line ranges with the generating edit, plus a byte-level robustness proptest over mutated real diffs. Both run in `fuzz.yml` at 400 cases. The byte-level target is a proptest rather than a cargo-fuzz target because cargo-fuzz needs nightly and a dependency class the repository policy gates do not admit. The differential found that a removal in a `+S,0` hunk got a `new_side_line` one low (#13098, fixed in #13508); its shrunk repro now runs as a regression test (#12918).
