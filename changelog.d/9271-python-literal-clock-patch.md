- Python: a test that fixes a zero-argument call with `patch("m.time.time", return_value=<literal>)` no longer makes ripr abstain when the edit is the arithmetic or text around that call, so an exact assertion credits it (RIPR-SPEC-0238 rule 8). The changed line must be one `return` of an f-string or `+`/`-` expression; an edit to the patched call's arguments, `*`, `//`, `%`, `max`/`min`, indexing, a branch, a zero or float stand-in and any other mock form still abstain. `py-idioms-patch-clock-separator` and `py-idioms-patch-clock-offset` move from abstained to credited (#9271).
