- The reveal side refuses a non-`mut` `static` (and an annotated `let`) by its declared type: `static C: AtomicUsize = ZERO;` and `static C: Cell<u32> = make();` are no longer followed to their initializer, and a scalar `static X: u32 = { .. AtomicUsize .. }` is no longer refused for words in its initializer. Detection needs a known interior-mutable type name in the declared type or the initializer; a user type that only holds an atomic with no such name stays unrecognized, and a scalar name the file rebinds (`type u32 = ..`) no longer counts as scalar (#8112).
