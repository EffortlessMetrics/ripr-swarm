- A test whose only body is a compile-time trait-bound check (`assert_send_sync::<Wrapper>();`, a turbofish call with no value argument) is no longer read as an unknown-strength oracle. Linked to a changed owner only by `same_test_file`, it used to earn `observation yes` through the single-assertion fallback and lift `no_static_path` or `reachable_unrevealed` to `weakly_exposed`; it now reads as a test with no assertion (`reachable_unrevealed`, observation `no`). A helper call with an argument, a helper without a turbofish and a real assertion beside the marker keep their credit. Not covered: while the owner's own body names its own method name (`self.inner.get()` inside `get`), reach stays `weak` rather than `no`, so the class is `reachable_unrevealed` and not `no_static_path` (#10091).
