- Partial fix for #10091. A test whose only body is a compile-time trait-bound check (`assert_send_sync::<Wrapper>();`, a turbofish call with no value argument) is no longer read as an unknown-strength oracle, so it no longer earns `observation yes` or lifts a finding to `weakly_exposed` through a `same_test_file` relation; it reads as a test with no assertion (`reachable_unrevealed`, observation `no`). The issue's expected `no_static_path` is not reached: reach stays `weak` while the owner's own body names its own method name (`self.inner.get()` inside `get`), so only the observation credit is removed. The refusal is by shape, not by callee: every zero-argument turbofish call is dropped, including ambient-state helpers (`assert_valid::<Config>()`), method forms (`checker.assert_ready::<T>()`) and `assert_ok::<T>()?` (known fail-closed over-refusal). The check is line-based and reads a line's first callee, so a multi-statement line (`foo(); assert_send::<T>();`) is judged by `foo` and is neither refused nor admitted by this change (fail-open, other statement-splitting paths not measured). Calls with an argument, helpers without a turbofish and real assertions keep their credit (#10091).
