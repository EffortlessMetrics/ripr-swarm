- An owner (free function or inherent method) reached only through an `async fn` hop earns `helper_owner_call` credit only for a test that drives the hop: the call is `.await`ed in code the test executes (for example a `#[tokio::test]` body), or is the sole argument of a test-local poll-to-completion helper verified from source (RIPR-SPEC-0197). Every async hop between the test and the owner must `.await` its own callee, and the lowest hop must `.await` its call into an owner that may return a future (an `async fn`, an unreadable declaration, or a plain `fn` whose return type names `Future`/`Pin` or whose body holds an `async` block or closure, so a sync owner using a closure also needs that await under an async hop); a hop-local binding or nested `fn` named like the callee refuses. A test that only constructs or drops the future, a third-party `block_on` (`futures::executor`, `tokio::runtime`) and an undeclared or unreadable declaration stay at `same_test_file`. This extends the inherent-owner fail-closed rule to free-function owners while keeping credit for directly awaited tests and sole-argument verified poll helpers (#7415, #11065, #11151). Not credited (recall only): `block_on(async { load(10).await })`, a synchronous middle hop returning `impl Future`, stored-then-awaited futures, spawn/join, and third-party executors. "Driven" has the same execution parity as synchronous call credit: dead branches, code after `return`, `cfg(any())` items and zero-iteration loops are not excluded. A return type hidden behind a type alias is not seen, and the hop shadow guard is name-based: it refuses local bindings, nested `fn`s and any `as` rename to the callee's name in the hop's file (so `use other::different as inner;` refuses, while a rename to another name does not; a hop that plain-`use`s its callee is currently not credited either, observed and fail closed), but not glob imports, imports in other files or external items of the same name. The compact helper path (`inherent_helper_path_reaches_owner`) still refuses every async helper, a fail-closed divergence.
