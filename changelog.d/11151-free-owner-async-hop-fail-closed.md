- An owner (free function or inherent method) reached only through an `async fn` hop earns `helper_owner_call` credit only for a test that provably polls the hop: the call is `.await`ed in code the test executes (for example a `#[tokio::test]` body), or is the single argument of a test-local poll-to-completion helper verified from source (RIPR-SPEC-0197), and every async hop between the test and the owner awaits its own callee. A test that only constructs or drops the future (a held binding, `drop`, an `async` block or closure that is never run, a second unpolled call), a third-party `block_on` (`futures::executor`, `tokio::runtime`) and an undeclared or unreadable declaration stay at `same_test_file`. This extends the inherent-owner fail-closed rule to free-function owners without the recall loss for ordinary awaited async tests (#7415, #11065, #11151).
